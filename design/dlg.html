DH · Dialogs

when a dialog is allowedThree, and no more

This system answers a refusal by making the thing that cannot pay flinch — the Stress track, the Hope pool — rather than by opening a box to explain it over the top of the number that already said no. A dialog is only allowed for a decision with more than one part, taken once, that changes the sheet underneath it. There are exactly three: how much armour to spend against a number you have just been shown, which two traits a level-up raises, and which downtime moves you are making. Each is a sentence you are still composing rather than a record you are editing, which is what the roll popover is — at a size a popover cannot hold.

Both of the two below draw cards, and neither draws one of its own. The rules a character carries are printed on objects they are holding, so the panel shows the object; a downtime move is the same kind of thing you pick up, so it takes the card's shape. Nothing here is a second dialect for something the table already reads elsewhere.

What both panels also do is rank what they found. A rule that mentions armour is not the same as a rule that can spend something to stop this hit, and a card that says “once per rest” is not the same as one that changes the rest — the first of each pair is arithmetic the sheet has already done or a receipt it is about to write. So the damage dialog drops the passives entirely and the rest gives the receipts a lane of their own, one step quieter.

Every rule is a line, in both lanes. Five tiles is five hundred pixels of panel under a dialog whose controls are all above it, and a reader scrolling a deck to find one name is not being helped by the pictures. What a line opens is the one distinction left worth drawing: a class feature is printed on nothing — you cannot spend it, move it or lose it, the text is the whole of it — so the line opens the rule. A domain card, ancestry, community or subclass, or the armour you are wearing, is an object in somebody's hand, so the line opens the card.
