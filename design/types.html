// A · FIVE TYPES, ONE COMPONENTDomain · Class · Subclass · Ancestry · Community

The corner slots are slots, not fixtures. A level numeral appears only if the card has one, a second sigil plate only if the card belongs to two domains, the recall chip only if there is a cost — so Ancestry and Community collapse to a bare plate holding their type glyph and nothing on the right. The gold divider is one continuous line: flat across the panel, up the badge's slope, then along its top edge to the card's right edge. The art plate never exceeds half the card height, so a sparse card gets white space above the footer instead of a plate that swallows the composition. Subclass takes its two colours from its class's domain pair rather than any invented palette: Bard = Grace + Codex, Rogue = Grace + Midnight. Graphite on Ancestry and Community, with the ramp suppressed, so a saturated hue on a card always means domain.

// B · TYPE GLYPHSDrawn, not sourced

Ancestry and Community have no sigil, so they needed one. Both are deliberately geometric — the nine domain marks are organic silhouettes and a type glyph should not be mistaken for one. Ancestry is two interlocking diamonds knocked through with fill-rule:evenodd, since a stroked outline fills in solid at ~14px. Community is three hexes with ~20-unit gaps so they stay separated rather than blobbing.

// C · CLASS MARKSNine, and none of them a sigil

A class card's corner plates carry its two domains, because that is what a class is — Ranger is Bone and Sage and the duo treatment says so without a word. But a class in a sidebar row, a compendium list or a hotbar slot has no card and no plates, and "Ranger" next to a grey square is the same square as "Rogue". These are that face — and the class card's own fallback plate in A above, which is the same problem stated the other way round: there the plates are present, so repeating one of them at plate size is the thing that says nothing. Same rules as the type glyphs above: chamfered, solid, one currentColor path family, no interior gutter under ~20 units. Two collisions had to be designed around rather than ignored. Ranger is not an arrowhead, because primary.svg already is one and a class mark that reads as a weapon slot is worse than none. Guardian is not a shield, for the reason armor.svg is not either — the rail already spends a shield on Armor Score. The one redundancy left standing is Wizard, whose book echoes its own Codex domain; the alternative was a staff, which is the Druid conifer's silhouette at list size.
