// THE SPLITTwo owners, two places, one geometry

Hope is per-character: six slots, spent on purpose, carried between sessions, and permanently crossed out by scars — cross out the last one and the character's journey ends, so the track has three states, not two. Fear is the GM's: twelve, and the rules explicitly say to keep this pool visible to players, so it is not a GM-only panel — it is a public strip docked in Foundry's own chrome, outside every sheet. They never sit next to each other, which is exactly what lets them share a shape without reading as one bar.

Gold stays chrome everywhere else in this system — a 1.5–2px line, never a fill. That is what frees it to mean Hope here: this is the only place in the interface where gold is a filled shape. Fear is the same object in violet, so nothing has to be re-learned to read the GM's strip.

// THE GEMA lit pane of glass, not a bead

A square turned 45°, because every other component in this system is a chamfered rectangle — it is the one silhouette that belongs to nothing else, and it is what the printed sheet already uses for Hope. A lit gem is flat colour: no shading gradient, no specular. All the depth is at the boundary — a bright rim where the light exits the edge, a refraction band falling off inward from it, and a bloom outside. The bloom follows the diamond, via a drop-shadow on a wrapper rather than a box-shadow on the shape; painting order is filter then clip-path, so a shadow declared on the clipped element gets trimmed away by the very outline it was meant to describe.

There is no idle animation anywhere. Six things breathing on a character sheet is six things asking for attention all day for nothing; the whole motion budget is spent on the moment the value changes, which is the only moment that carries information. A scarred slot is struck through with two strokes that overhang the shape — a permanent wound, drawn the way you would cross something off on paper, not a hatch fill that reads as merely unavailable.

// IN PLACEHope in the sheet header band

The band carries identity, the four always-visible numbers, and Hope. Nothing else on the sheet is gold-filled, so the eye goes straight to it without the pool needing to be large.

// IN THE HUDTwelve, docked in Foundry's chrome

Public to the table — the rules ask the GM to keep the pool visible. Players see the same strip without the steppers. Drag the fear slider or use the steppers; the whole strip's glow eases up behind the pip that changed, which is what sells twelve as worse than eleven.
