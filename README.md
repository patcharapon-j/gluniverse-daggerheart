# gluniverse-daggerheart

A [Foundry VTT](https://foundryvtt.com/) **v14** game system for [Daggerheart](https://www.daggerheart.com/).

> Status: early development. Not yet playable.

## Install

Not published yet. To develop locally, clone into your Foundry `Data/systems` folder:

```sh
git clone https://github.com/<you>/gluniverse-daggerheart.git
```

Then enable it when creating a world. Requires Foundry VTT v14+.
